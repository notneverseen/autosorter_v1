# file autosorter script by neverseen
Автоматический скрипт сортировки файлов по папкам (видео, фото, музыка, etc)

# how to start
1. Запустите скрипт: 'python autosorter.py' / 'python3 autosorter.py'
2. Введите название папки для сортировки
3. Скрипт создаст подпапки ('video', 'image', 'music', etc) в текущей директории переместит в них файлы

# requirements
Python 3.6+ (использованы стандартные библиотеки)
